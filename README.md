Sobre o projeto
A proposta foi criar uma landing page para uma cafeteria com temática praiana, utilizando uma paleta de cores e elementos visuais que remetem ao mar, areia e ambiente tropical.

Este projeto tem caráter experimental e educacional, servindo como prática de desenvolvimento de interfaces utilizando HTML e CSS.

⚠️ Observação: este projeto é apenas um protótipo e não possui responsividade. O layout foi desenvolvido pensando principalmente na visualização em desktop.
🛠️ Tecnologias utilizadas
HTML5 — Estrutura e organização do conteúdo.
CSS3 — Estilização, cores, tipografia e layout.
🎨 Características
🏖️ Tema inspirado em praia
☕ Identidade visual de cafeteria
🎨 Paleta de cores inspirada no mar e na areia
🖼️ Elementos visuais relacionados ao tema
💻 Layout desenvolvido como protótipo para desktop
✨ Interface simples e moderna
